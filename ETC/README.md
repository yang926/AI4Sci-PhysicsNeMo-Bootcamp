# Supporting files

Students start at [Start Here](../Start_Here.ipynb). The numbered Lab and Challenge folders contain the lessons and exercise code.

| Folder | Contents |
|---|---|
| [course_materials](course_materials/README.md) | Instructor guide, schedule, supplementary Wave example, and validation tools. |
| [environment](environment/SETUP.md) | uv installation, connection instructions, and container files. |
| `runtime` | Shared training, evaluation and notebook-result helpers imported by the lessons. |
| `tests` | Automated checks for equations, execution, and course links. |
| `validation-runs` | Local check reports and executed notebook copies; excluded from Git. |
| `assets` | Supporting images. |
| `legacy` | Earlier guides, figures, and datasets retained for reference. |

Students do not need to run the tests or read the validation reports. Keep `runtime` in place: the lesson programs import it. For teaching, use the [instructor guide](course_materials/INSTRUCTOR.md), [schedule](course_materials/course-plan.md) and [assessment guide](course_materials/ASSESSMENT.md).
