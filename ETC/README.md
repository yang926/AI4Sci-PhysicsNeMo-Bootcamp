# 지원 파일

학생은 [시작하기](../Start_Here.ipynb)에서 시작합니다. 번호가 붙은 실습 및 도전 과제 폴더에 수업 자료와 연습 코드가 있습니다.

| 폴더 | 내용 |
|---|---|
| [course_materials](course_materials/README.md) | 강사 안내, 일정, 파동 보충 예제, 검증 도구. |
| [environment](environment/SETUP.md) | uv 설치, 연결 안내, 컨테이너 파일. |
| `runtime` | 수업에서 가져다 사용하는 공통 학습, 평가, 노트북 결과 보조 함수. |
| `tests` | 방정식, 실행, 강좌 링크 자동 검사. |
| `validation-runs` | 로컬 검사 보고서와 실행된 노트북 사본. Git에서 제외됩니다. |
| `assets` | 보조 이미지. |
| `reference_labs` | 보관된 Navier–Stokes PINN 실습, 원본 데이터, 과거 시연 자료. 현재 실습 4는 사전 학습된 FourCastNet을 활용한 일기 예보입니다. |
| `legacy` | 참고용으로 보관한 이전 안내, 그림, 데이터셋. |

학생은 테스트를 실행하거나 검증 보고서를 읽을 필요가 없습니다. 수업 프로그램이 가져다 사용하므로 `runtime`을 제자리에 유지하세요. 수업에는 [강사 안내](course_materials/INSTRUCTOR.md), [일정](course_materials/course-plan.md), [평가 안내](course_materials/ASSESSMENT.md)를 사용하세요.
