# 한국어판과 원본 보존 검증

한국어판은 영문 `main`의 `e494c250287a90fa5f6662236a8feefe1a620885`를 기준으로 만든 별도 `ko` 브랜치입니다. 영문판과 영문 행사 Launchable은 변경하지 않습니다.

## 번역 범위

- 시작 안내, 환경 설정, 소개, 실습 1–4, 도전 과제 1–4: 노트북 11개의 설명
- 수업용 도식 17개와 강사·학습·설치·평가·제출 안내
- 한국어판 설치와 갱신 스크립트: 항상 `ko` 브랜치를 사용

실행 셀, Python 실습 코드, 방정식, 학습 설정, 데이터는 영문판 그대로입니다. API 이름, 실제 버튼 이름, 코드 주석, 실행 로그, 실행 시 생성되는 그래프의 축 이름은 원문을 유지합니다. 역사적 검증 기록과 보관된 참고 실습, 기존 스크린샷, 라이선스 문구는 번역 대상에서 제외했습니다. 학생 자료에 정답을 추가하지 않았습니다.

## 채점 연결

한국어 Launchable과 작업 공간의 채점 연결은 주최 측이 별도로 관리합니다. 채점 연결 상태는 각 도전 과제의 마지막 제출 패널에서 확인하세요. 연결된 작업 공간에서는 닉네임을 등록하고 코드를 제출할 수 있습니다. 연결 없이도 로컬 실습과 저장된 코드 확인은 사용할 수 있습니다. 한 작업 공간의 연결 완료가 앞으로 생성하는 모든 작업 공간의 자동 연결을 의미하지는 않습니다.

## 검사 방법

저장소 루트에서 실행합니다.

```bash
python ETC/localization/validate_ko.py
python ETC/course_materials/validate_materials.py --language ko --output /tmp/ai4sci-ko-materials.json
```

첫 검사는 `english-baseline.json`에 기록된 원본 커밋의 실행·설정·데이터 파일 92개와 노트북 11개의 전체 코드 셀을 비교합니다. 두 번째 검사는 노트북 형식, 링크, 소스 구문 및 수업 구조를 확인합니다. 기호식과 번역의 의미, 도식의 가독성은 별도 검토했습니다.

2026년 9월 30일 로컬 검사에서 두 검사와 `git diff --check`가 통과했습니다. 설치·체크아웃·갱신·Jupyter·프록시 회귀 테스트는 총 207개가 통과했습니다. 실제 Jupyter 서버 기동 테스트 1개는 샌드박스의 네트워크 제한 때문에 제한 없는 환경에서 별도로 재실행했습니다. 이는 새 한국어판으로 모든 학습을 다시 수행했다는 뜻은 아닙니다.
