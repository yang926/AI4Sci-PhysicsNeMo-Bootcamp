00_Start_Here에서 실제 참가자 커널의 Python, PhysicsNeMo, PyTorch, CUDA와 GPU를 확인합니다. FNO 데이터는 원본 기본 split으로 미리 생성합니다. 이 교재는 9월 코드에서 필요한 실행 경로를 분리한 것으로, 새 환경에서 실행 가능 여부는 리허설로 확인해야 합니다.

01_PINN은 완성된 forward 코드로 1,000회 L-BFGS 호출을 실행합니다. 출력의 heldout_after와 accuracy를 확인합니다. 학생은 실제 출력 배열을 사용해 그리는 코드만 AI에 요청합니다. 해석해는 학습 target이 아닙니다.

02_FNO는 두 함수가 빈 학생판입니다. AI의 답변을 직접 붙여 넣고 2-step 실행 확인 뒤 3,000-step 본 학습을 합니다. 2-step 성공은 정확도 통과가 아닙니다. 8000/1000/1000 split, seed 42, grid 64, 모델 설정, 학습 예산, 평가를 유지합니다. 이번 수업은 FNO Level 1만 다루며 AFNO/PINO를 새로 구현하는 과정은 없습니다.

## 설명할 핵심

PINN에서는 좌표 미분과 파라미터 gradient를 구분하고, 방정식과 경계조건이 각각 왜 필요한지 설명합니다. 해석해와 일치하는지, 잔차와 경계 오차도 작은지 함께 봅니다.

FNO에서는 하나의 좌표가 아니라 전체 forcing field가 입력임을 보여 줍니다. 서로 다른 forcing에 대한 해를 학습하며, train에 사용하지 않은 test field에서 확인합니다. 정규화 통계는 train만 사용합니다. 작은 field error가 작은 미분 잔차를 보장하지 않는다는 점을 설명합니다.

AI가 만든 코드를 참가자가 읽고 실행합니다. AI에 실험 실행, 자동 튜닝, 결과 판정이나 보고서 작성을 맡기는 수업이 아닙니다.
